# Agent workflow delivery

Scope: Upstream parity.

[Index](../README.md) · [Critical review](../../REVIEW.md)

## Requirements

- [ ] **R56** Update shall detect every tool installation generated by init.
- [ ] **R57** Init shall generate only the workflows selected by the active profile.
- [ ] **R58** Update shall apply the configured workflow delivery mode.
- [ ] **R59** Codex workflow skills shall be installed under `.agents/skills`.
- [ ] **R60** The `agents` tool target shall install workflow skills under `.agents/skills`.
- [ ] **R61** Tool-installation migration shall preserve user-customized files.
- [ ] **R62** Generated workflow handoffs shall reference only installed workflows.

## Scope notes

R61 applies to tool-location migration. It does not introduce a general promise that regeneration preserves edits to generated files.
